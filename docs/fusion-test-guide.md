# 炼妖测试数据使用说明

## 生成接口

`POST /api/dev/seed-fusion-pets`

该接口：

- 直接使用当前默认测试账号。
- 不创建用户 203。
- 不删除当前账号原有宠物。
- 仅非生产环境可用。
- 可重复调用，不会重复增加同一组测试宠物。

## 生成内容

PET001～PET010 每个物种：

- 2 只变异宠物。
- 2 只普通宠物。

总计：

- 20 只变异宠物。
- 20 只普通宠物。
- 40 只炼妖测试宠物。

测试宠物统一标记：

```text
sourceType = fusion_test_seed_v1
```

固定昵称示例：

```text
炼妖变异-PET001-A
炼妖变异-PET001-B
炼妖普通-PET001-A
炼妖普通-PET001-B
```

## 自动补充

- 宠物容量不足时提升到至少 100。
- `fusion_core` 至少 200。
- `skill_lock` 至少 100。
- `mutation_essence` 至少 30。
- 金币至少 100000。
- 钻石至少 1000。

## 自动验证

接口返回：

- 变异宠物 20 只。
- 普通宠物 20 只。
- 十个物种完整覆盖。
- 所有变异宠物至少一个特殊技能。
- 所有普通宠物没有特殊技能。
- 所有宠物技能数不超过技能格。
- 本次实际创建数量与是否命中幂等。
- 完整宠物清单、资质、成长、技能和特殊技能数量。

## Cocos 开发入口

`DevFusionTools` 可绑定一个开发工具根节点、按钮和结果 Label。它只在 `DEV` 环境显示，正式包不提供测试数据按钮。

建议验证步骤：

1. 启动后端。
2. 在非生产环境调用生成接口，或点击开发按钮。
3. 进入宠物页或炼妖页刷新数据。
4. 分别选择普通、变异、单特殊和多技能宠物进行炼妖。
5. 再次调用生成接口，确认测试宠物总数仍为 40。

## 注意

- 不要手工把特殊技能写入普通宠物。
- 变异特殊技能由现有 `PetService` 按物种配置添加。
- 锁定技能只允许普通/高级技能；特殊技能不可锁定。
- 请求失败时不得重复扣除炼妖材料或生成两个结果。
