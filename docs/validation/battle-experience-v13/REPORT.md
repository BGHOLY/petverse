# PetVerse V13.3 正式战斗资产与体验验收报告

验收日期：2026-08-15  
分支：`battle/v13.3-asset-performance`  
基线：`c6cd3d0`（V13.2 第一章战斗垂直切片）

## 结论

V13.3 已完成“正式战斗资产接入底座、表现反馈、性能分级与可重复验收”四项工程闭环：

`正式 Prefab 合同 → 导入校验 → 本地/远程加载 → 安全回退 → 自适应画质 → 战斗反馈 → 自动审计与真实接口冒烟`

当前代码可以在不重写战斗逻辑的前提下接入外包或自制的正式 3D 宠物与首领 Prefab。未通过动作、节点、材质和面数校验的资源不会进入战斗；加载失败、资源未批准或远程 Bundle 不可用时会自动使用程序化 3D 样板，避免黑屏或战斗中断。

本阶段没有把程序化样板伪装成正式模型。仓库目前仍缺少经过 DCC 制作、蒙皮和动作验收的正式 FBX/GLB/Prefab，因此所有物种的 `formalAssetReady` 继续保持关闭。这是外部资产生产依赖，不是运行时接入缺口。

## 功能交付

### 正式资产生产与加载

- 为 PET001—PET010 与 BOSS001 建立统一生产档案。
- 明确 Prefab 路径、远程 Bundle、三角面、节点、材质、渲染器和压缩预算。
- 正式资源必须包含 `Idle / Attack / ActiveSkill / Hit / Death / Victory / Entry` 七套动作。
- 新增运行时资产校验，拒绝缺动作、超预算或含禁用组件的 Prefab。
- 支持本地 `resources` 与 HTTPS 远程 Asset Bundle 两种交付方式。
- 支持微信 `extConfig` 和运行时全局配置提供战斗资产 CDN 根地址。
- 战斗关闭时释放 Prefab 引用，避免多场战斗后持续占用资源。
- 防止异步加载完成后把旧宠物模型覆盖到已切换物种的槽位。

### 自适应画质与性能保护

| 档位 | 目标帧率 | 程序化几何细分 | 同屏临时特效 | 次级反馈 |
|---|---:|---:|---:|---|
| 低 | 30 FPS | 低 | 3 | 关闭 |
| 均衡 | 45 FPS | 中 | 6 | 开启 |
| 高 | 60 FPS | 高 | 10 | 开启 |

- 默认使用 `auto`，根据微信设备基准等级、内存与开发工具环境选择档位。
- 支持本地保存玩家画质偏好。
- 限制同屏临时特效数量，达到上限时安全跳过次要特效。
- 大型 battleLog 分批播放并主动让出帧，不丢失服务端事件。
- 镜头震动、冲击波、Boss 预警和命中特效按画质档位降级。
- 战斗退出时恢复进入战斗前的帧率设置。

### 战斗反馈

- 普通命中增加短促冲击爆发。
- Boss 预警延长到可读时长，并增加范围波纹。
- 阵法、主动技能、受击、胜利和失败统一通过战斗音频路由播放。
- 对重复音效进行节流，避免大量事件同时到达时形成噪声叠加。
- 战斗诊断会记录正式/回退角色数量、临时特效峰值与跳过次数。

## 已知边界

- 正式 3D 模型、骨骼、蒙皮和七套动作仍需要 Blender/Maya 或合格外包完成；当前仓库只具备生产规范、校验、加载和无损替换能力。
- 本机 Web 预览验证了功能与运行错误，但 30/45/60 FPS 档位仍应在至少一台低端安卓、一台主流安卓和一台 iPhone 上做最终物理设备验收。
- 远程 Asset Bundle 已支持配置，但生产 CDN 地址、缓存策略和跨域头需要在正式资源交付后由实际部署环境确定。
- 程序化 3D 样板仍是安全回退资源，不能用于对外宣称正式美术品质。
