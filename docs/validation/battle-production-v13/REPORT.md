# PetVerse V13.1 战斗生产切片验证报告

## 本阶段范围

本阶段把战斗从“图片碰撞”推进到可替换正式资源的 3D 生产切片，覆盖：

- PET001 炎尾狐、PET002 岩甲龟、PET008 森灵鹿与 BOSS001 古树守卫；
- 进场、待机、普攻、主动技能、受击、死亡、胜利七套动作合同；
- 普通五宠战、首领战、集火、阵法能量与阵法大招；
- 首领预警、下一回合专属技能与二阶段转场；
- 服务端判定、稳定事件 ID、掉线恢复数据与幂等结算；
- 正式 Prefab 未就绪时的程序化 3D 样板回退。

本阶段没有把参考图打进运行包，也没有把未经过模型、动作、包体和真机验收的资源标记为正式资源。

## 微信包体结论

当前已有微信构建产物共 547 个文件、36.37 MiB，其中本地资源 34.75 MiB、引擎约 1.45 MiB、除资源外运行时代码约 1.62 MiB。程序化 3D 样板与参考四视图不是本次包体的主要矛盾；现有 2D `resources` 资源才是主要占用。

当前产物可以用于本地功能验证，但仍未通过保守的 20 MiB 上传门槛。正式上传前必须取得真实 HTTPS CDN 地址，并将大背景、全量宠物图、音频与后续正式 3D 模型拆到远程 Asset Bundle；仓库没有安全可推断的生产 CDN，因此本阶段没有写入伪地址。

## 当前唯一外部依赖

正式骨骼模型仍需要 Blender/Maya 等 DCC 工具或合格的外包资产生产。仓库当前具备无损替换正式 Prefab 的接口，不需要为了换模型重写战斗逻辑。

Cocos Creator 当前机器出现开发者登录窗口；这不影响代码、接口和自动审计，但最终编辑器预览、微信构建与真机录像仍需要有效的 Cocos 登录会话。

本机已按 Cocos 3.8.8 命令行构建规则尝试重新生成微信包，但由于当前没有有效的 Cocos 登录会话，未生成新的 V13 构建日志和产物。因此不能把旧产物冒充为本次新构建。完成登录后只需重新执行正式构建、运行包体报告，并在微信开发者工具录制普通战与首领战真机表现。
