# PetVerse 3D 战斗资源预算 V1

## 1. 资源组织

```text
主包
├─ 登录、启动、核心脚本
├─ 最小公共 UI
└─ 下载与错误界面

本地分包
├─ ui-common
├─ home-starter
└─ chapter-01-shell

远程 Asset Bundle
├─ battle-common
├─ pet-starter-01
├─ pet-pack-02
├─ battle-chapter-01
├─ battle-vfx-common
└─ pet-skins
```

微信小游戏不能远程加载脚本。远程 Bundle 只保存模型、贴图、动画、音频、特效和场景资源，逻辑脚本留在代码包。

## 2. 单宠战斗预算

| 项目 | 普通宠物目标 | Boss 目标 |
|---|---:|---:|
| 三角面 | 5,000～12,000 | 15,000～25,000 |
| 骨骼 | ≤40 | ≤60 |
| 材质 | 1，最多 2 | 最多 3 |
| 主贴图 | 512×512 | 1024×1024 |
| 实时灯光 | 1 个主光 | 1 个主光 |
| 实时阴影 | 关闭 | 关闭或仅高档开启 |
| 同屏实例 | 最多 10 | Boss + 5 玩家 + 少量召唤物 |

首页展示可以使用更高精度版本，战斗统一使用战斗 LOD。脚底使用投影贴片代替实时阴影。

## 3. 动画标准

每只宠物首批至少提供：

- `enter`
- `idle`
- `basic_attack`
- `active_skill`
- `hit`
- `death`
- `victory`

同体型宠物优先共享骨架与 `enter/idle/basic_attack/hit/death/victory`，只保留主动技能专属动作。

## 4. 运行时预算

- 低档目标：30 FPS；
- 高档目标：60 FPS；
- 单宠尽量 1 Draw Call，特效按公共材质合批；
- 粒子、飘字、弹道全部使用对象池；
- 单次主要攻击控制在一个主特效和两个以内辅助特效；
- 同屏全透明大粒子不得持续叠加；
- 战斗关闭后 5 秒内不应继续持有章节与宠物 Bundle 的无用实例。

## 5. 下载预算

- 主包内部目标：≤3.2 MiB；
- 本地全部代码包与分包内部目标：≤18 MiB；
- 首次进入样板战斗额外下载：≤6 MiB；
- 单个宠物包建议：≤2 MiB；
- 公共战斗与特效包建议：≤3 MiB；
- 后续宠物、章节、皮肤按需下载并进行版本缓存。

每次微信构建必须输出主包、分包、远程包、最大单文件和重复依赖报告。
