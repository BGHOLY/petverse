# PetVerse V10.2 UI 设计规范

## 产品目标

V10.2 不增加大型玩法系统，目标是把现有版本从“功能完整的开发版”提升为可邀请外部玩家体验的测试版本。

页面必须共同服务以下核心循环：

> 领取收益 → 培养宝宝 → 炼妖或孵化 → 调整阵容 → 继续冒险

任何低频功能都不能获得与核心行动相同的视觉权重。

## 画布与安全区域

- 设计画布：`720 × 1280`
- TopBar：`112`
- BottomNavigation：`150`
- 左右安全边距：`24`
- 内容区上下留白：`16`
- 内容宽度：`672`
- 模块间距：`16`
- 小间距：`8`

页面背景可以铺满内容区，但按钮、文字、列表和滚动内容必须避开顶部与底部固定栏。

## 视觉语言

- 氛围：温暖、精致、柔和、轻幻想、治愈
- 主要材质：奶油纸张、浅木材、花草、少量金色
- 普通页面禁止使用纯黑底
- 黑色只用于画布外留黑和半透明遮罩
- 一个页面最多有一个一级主按钮
- 装饰不能压过宠物、炼妖结果或主线进度

## 色彩层级

- 页面底色：暖奶油色
- 普通卡片：浅纸色
- 选中和主操作：蜂蜜金
- 成功和可领取：薄荷绿
- 风险与重要警告：柔和珊瑚红
- 特殊技能和稀有内容：淡紫色
- 次要文字：深暖灰棕，禁止使用低对比度浅灰
- 禁用状态：降低饱和度，同时必须显示禁用原因

## 字体层级

- 页面标题：`24–28`
- 模块标题：`18–22`
- 卡片名称：`16–18`
- 正文：`14–16`
- 辅助信息：不低于 `12`

页面标题由 TopBar 动态显示，禁止把页面名称继续烘焙进通用图片。

## 卡片与按钮

- 大卡片圆角：`24`
- 小卡片圆角：`16`
- 一级按钮高度：`72`
- 二级按钮高度：`56`
- 列表项高度：`88–104`
- 普通商品：每行 2 个
- 功能入口：最多每行 3 个
- 背包和蛋仓库：每行 4 个

一级按钮使用金色或页面专属强调色；普通按钮不得与一级按钮同等醒目。

## 页面状态

每个数据页面必须具备：

1. 加载中
2. 正常内容
3. 空状态
4. 加载失败
5. 按钮禁用及原因

接口失败不得清空已有内容，也不得把玩家送回首页。

## 动效规则

- 按钮按压缩放：轻微且快速
- 页面转场：淡入或短距离滑动
- 数值变化：只更新相关区域
- 孵化、炼妖和获得宠物允许使用较强演出
- 普通列表和设置页面不使用大量粒子

## 核心页面优先级

1. 首页
2. 宠物
3. 炼妖
4. 孵化
5. 冒险
6. 商店、背包、技能
7. 好友、结婚、排行、邮件、设置

## 编辑器与代码职责

- 用户可在 Cocos 中调整静态节点的位置、大小、锚点、图片、字体和层级。
- 固定 UI 不允许在运行时被代码重新定位或销毁。
- 动态列表由 Prefab 实例化，视觉只在 Prefab 中维护。
- 数据刷新只能更新相关 Label、Sprite 和状态，不重建整个页面。
- TopBar、BottomNavigation、OverlayRoot 和页面根节点不得随意重命名或删除。

## V10.2 孵化室方向

孵化室采用“温暖魔法温室”：

- 上半部为场景化的三个实体育宠窝
- 蛋直接显示在窝中，并展示倒计时和完成状态
- 蛋仓库通过下方抽屉打开
- 仓库每行四格
- 孵化完成时使用场景高亮和领取提示

如果现有资源不足，先完成结构与占位，不使用廉价伪场景替代最终美术。
