# PetVerse V2 核心玩法基线

## 一句话定位

PetVerse V2 是一款以免费玩家为主的微信宠物养成小游戏：

> 挂机获得资源，炼妖追求独特技能宠物，再用五宠阵容、阵法和轻量战术挑战战斗内容。

## 核心循环

1. 领取离线与远征收益。
2. 培养宠物等级、资质和成长。
3. 使用技能书与炼妖材料调整技能组合。
4. 通过炼妖赌技能格、普通/高级/特殊技能、资质、成长与变异。
5. 配置五宠编队、站位、阵法和三项全队战术。
6. 挑战主线、首领、爬塔和异步战斗。
7. 获得更高级的培养、技能和炼妖资源。

## 首版系统范围

### 宠物与炼妖

- PET001～PET010 十个基础物种。
- 普通宠物与变异宠物。
- 每个物种拥有固定主动技能和变异特殊技能。
- 普通、高级、特殊技能可参与继承。
- 技能格可能增加或减少，不能保证越炼越多。
- 资质、成长可能高于或低于父母。
- 变异状态不保证继承。
- 锁定普通/高级技能需要消耗 `skill_lock`。
- 炼妖主体消耗 `fusion_core`。
- 特殊技能不能作为锁定技能，但可以按受控概率继承。

### 五宠战斗

- 五只宠物自动战斗。
- 玩家在战前配置目标、技能与生存策略。
- 宠物拥有普通攻击、主动技能、被动与状态效果。
- 战斗使用可复现随机种子，便于复盘和自动测试。
- 战斗日志记录战术、阵法与技能连携的触发原因。

### 三项轻量战术

- 目标策略：前排、后排、最低血量、治疗单位、首领。
- 技能策略：立即释放、控制连携、首领蓄力、残血收割。
- 生存策略：残血治疗、后排援护、低血量阵法技、全力进攻。

### 阵法

每个阵法由四部分组成：

- 五个站位加成。
- 一条战术被动。
- 一个阵法大招。
- 阵法能量与触发条件。

现有五阵法代码继续兼容：`dragon`、`turtle`、`crane`、`tiger`、`phoenix`。

### 通用技能连携

首版只保留六种低成本通用反应：

1. 灼烧 + 火系：烈焰爆发。
2. 潮湿 + 雷系：感电。
3. 冰冻 + 重击：碎冰。
4. 标记 + 追击：追加攻击。
5. 过量治疗：转化护盾。
6. 护盾 + 反击：坚壁回震。

反应有单回合触发上限，不允许无限连锁。

### 轻量挂机远征

- 地图：森林、火山、冰原、遗迹。
- 时长：30 分钟、2 小时、4 小时、8 小时。
- 每支队伍 1～5 只宠物。
- 远征宠物不能同时参加另一支远征。
- 奖励由服务器计算，不能提前或重复领取。
- 不做宠物死亡、复杂剧情树、长期性格或默契系统。

### 社交与孵化

现有好友、结婚、生蛋、孵化逻辑继续保留。生蛋规则后续单独按产品基线调整，本轮核心玩法升级不破坏现有数据。

## 当前明确不做

- 宠物长期 AI 性格。
- 动态远征故事树。
- 复杂默契关系。
- 家族记忆与多代外观生成。
- 每只宠物自由编程。
- 装备、宝石、符文等额外养成线。
- 大量专属组合技动画。

## Cocos 协作边界

- 用户负责所有固定 UI 的位置、大小、锚点、图片、字体、颜色和排版。
- 代码只负责数据、状态、事件、页面切换、动态列表与必要动画。
- 固定 UI 不得在运行时重建或重新定位。
- 非首页页面仍在逐页迁移，迁移前保留 `RuntimeContent` 以保障原功能。
