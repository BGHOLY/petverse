# PET001 炎尾狐：3D 生产规格 V1

## 1. 角色定位

- 物种代码：`PET001`
- 中文名：炎尾狐
- 战斗定位：火系法术爆发、快速收割
- 性格关键词：聪慧、亲人、轻盈、勇敢
- 核心剪影：大耳、短躯干、清晰四肢、单条大型火焰尾
- 参考图：`docs/art/characters/pet001-flame-tail-fox-turnaround-v1.png`

参考图用于锁定造型、色彩和纹样。它不是游戏内贴图，不得直接放入客户端资源包。

## 2. 造型锁定

### 必须保留

1. 奶油白主毛色，橙金色耳尖、四肢和尾焰。
2. 额头月牙形火纹，左右脸颊各一组火纹。
3. 单尾设计。尾巴是第一识别特征，不得改为多尾。
4. 紫金渐变眼睛与小型月光石吊坠。
5. 头身比例约 `1 : 2.25`，可爱但不做幼儿化大头娃娃。
6. 站立时脚底、尾尖和双耳均完整落入角色包围盒。

### 禁止事项

- 不增加武器、盔甲、大面积服装或复杂首饰。
- 不使用写实长毛卡片；战斗版以模型轮廓和烘焙毛色表现绒感。
- 不增加第二条尾巴、翅膀或持续遮挡身体的粒子。
- 不改变四视图中的纹样位置、眼睛颜色和吊坠结构。

## 3. 模型规格

| 项目 | 战斗版要求 |
|---|---|
| 三角面 | 8,000 目标值，5,000～12,000 可接受 |
| 材质 | 1 个为目标，最多 2 个 |
| 主贴图 | 512×512，BaseColor + 可选压缩 Mask |
| 骨骼 | 24 根目标值，不超过 30 根 |
| 模型高度 | 耳尖约 1.85 Cocos 单位 |
| 原点 | 四足投影中心，脚底 `Y=0` |
| 正面 | 朝向 Cocos `-Z` |
| 缩放 | 导出前烘焙为 `1,1,1` |
| 阴影 | 不使用实时阴影，使用战场公共脚底投影 |

首页展示版以后可以使用 1024×1024 贴图和独立高模，但不得替换本战斗版资源。

## 4. 骨架命名

```text
Root
└─ Hips
   ├─ Spine_01
   │  ├─ Spine_02
   │  │  └─ Neck
   │  │     └─ Head
   │  │        ├─ Ear_L
   │  │        ├─ Ear_R
   │  │        └─ Jaw
   ├─ FrontLeg_L_01 / 02 / Paw
   ├─ FrontLeg_R_01 / 02 / Paw
   ├─ BackLeg_L_01 / 02 / Paw
   ├─ BackLeg_R_01 / 02 / Paw
   └─ Tail_01 / 02 / 03 / 04 / 05
```

- `Root` 不做战斗位移，所有冲刺由战斗舞台控制。
- 尾巴至少 5 段，耳朵各 1 根骨骼。
- 眼睛允许使用 2 根控制骨；不使用高成本 BlendShape。

## 5. 动画规格

| Clip | 时长 | 循环 | 关键帧/事件 |
|---|---:|---|---|
| `enter` | 0.80s | 否 | 0.62s 落地 |
| `idle` | 2.40s | 是 | 耳朵错位摆动、尾巴低幅呼吸 |
| `basic_attack` | 0.65s | 否 | 0.34s `impact` |
| `active_skill` | 1.25s | 否 | 0.78s `release`，此前至少 0.20s 尾焰收束 |
| `hit` | 0.30s | 否 | 头部和前肢受力，不大幅位移 |
| `death` | 1.00s | 否 | 侧卧收尾，不穿地 |
| `victory` | 1.60s | 否 | 尾焰扬起、轻跳，随后可回到 `idle` |

所有动画必须以同一骨架、同一原点导出；关闭 Root Motion。

## 6. 技能表现

### 普通攻击

- 身体下压后快速前扑，命中点与 `impact` 对齐。
- 不制作长距离位移动画，位移由 `Battle3DStage` 控制。

### 主动技能

- 尾焰先向身体收束，再形成一圈橙金能量并释放。
- `release` 前必须有玩家可读的蓄力阶段。
- 全屏亮度变化不超过 0.18 秒，防止连续技能造成视觉疲劳。

### 特殊技能“焚心尾焰”

- 复用公共火系命中特效和焚印状态图标。
- 特殊价值通过时序、焚印和二次伤害表达，不新建一套全屏演出。

## 7. Cocos 交付结构

```text
pet-starter-01/
└─ pets/PET001/
   ├─ PET001_Battle.prefab
   ├─ PET001_Battle.fbx
   ├─ PET001_Battle_Mat.mtl
   └─ PET001_Battle_BaseColor.png
```

Prefab 根节点必须命名为 `PET001_Battle`，不得包含 Camera、Light、UI、战斗逻辑或常驻粒子。

注册表路径：

```text
bundleName: pet-starter-01
prefabPath: pets/PET001/PET001_Battle
```

正式资源完成并通过检查后，才把注册表中的 `formalAssetReady` 改为 `true`。未通过时必须继续使用程序化质量样片，不能阻断战斗。

- [ ] 720×1280 战斗镜头下，仅看剪影可与龟、鹿区分。
- [ ] 十单位同屏低档真机保持 30 FPS。
- [ ] 七个必需动画名称完整且事件帧正确。
- [ ] 模型加载失败时自动回退，不影响服务端结算。
- [ ] 单宠战斗 Bundle 增量不超过 2 MiB。
- [ ] 微信构建不将参考图打入运行资源。
