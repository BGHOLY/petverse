## 专业判断

本次启用 3D、Primitive 与骨骼动画模块后，运行时代码仍处于可控范围。当前包体的主要矛盾不是 3D 战斗代码，而是已有的 2D 图片全部位于本地 `resources` Bundle，占构建总量约 95.5%。

按照微信小游戏主包不超过 4 MiB、主包与分包合计不超过 20 MiB 的保守发布门槛，当前 36.37 MiB 本地产物可用于 Cocos 与本地开发者工具验证，但不能作为正式上传包。

## 发布前必须完成

1. 保留登录、基础脚本、首屏 UI 与少量占位资源在本地包；
2. 把首页大背景、全量宠物图、商店图、音频和后续 3D 模型拆为远程 Asset Bundle；
3. 为远程 Bundle 配置 HTTPS CDN 地址与缓存版本；
4. 登录后按页面或战斗场景预下载，不在首屏一次下载全部资源；
5. 正式 3D 战斗首包额外下载继续控制在 6 MiB 内；
6. 使用真实微信 AppID 和 CDN 域名重新构建；
7. 在微信开发者工具与至少两台真机验证首包、缓存、弱网、二次进入和清理缓存后的行为。

CDN 地址与正式 AppID 属于部署参数，当前仓库没有可安全推断的生产值，因此本阶段不写入伪地址。发布包体门槛在获得这些参数后执行，玩法和浏览器/Cocos 测试不受此项影响。

## 检查命令


```text

```
